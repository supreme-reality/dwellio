# Dwellio Web

Next.js 15 (App Router) frontend for **Dwellio**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

API calls target the Spring Boot app at `http://localhost:8080` (Auth0 wiring comes in later phases). Specs live in `projectDocs/v5/`.
